# MariaDB Demo

Connect to MariaDB and run queries using the C API.

Requires MariaDB Connector/C and a test database. Set `COURSEWORK_DB_SERVER`, `COURSEWORK_DB_USER`, `COURSEWORK_DB_PASSWORD`, and `COURSEWORK_DB_NAME` before running.

## Build

Compile these source files together, with paths relative to this directory:

- `test_mariadb.cpp`
