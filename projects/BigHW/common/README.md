# Shared Implementations

Shared implementations for argument parsing, configuration files, strings, console and HDC drawing, mathematics, and database access.

Compile only the modules needed by each application.

## Build

Compile these source files together, with paths relative to this directory:

- `class_aat.cpp`
- `class_crt.cpp`
- `cmd_console_tools.cpp`
- `cmd_hdc_tools.cpp`
- `common_database_tools.cpp`
- `common_string_process.cpp`
- `common_frame_construction.cpp`
- `common_math_tools.cpp`
- `common_star_print.cpp`
