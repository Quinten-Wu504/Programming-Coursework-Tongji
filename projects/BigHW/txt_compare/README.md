# Text Comparison

Compare two text files using configurable command-line options and shared string-processing utilities.

Provide the two files to compare.

## Build

Compile these source files together, with paths relative to this directory:

- `../common/class_aat.cpp`
- `../common/cmd_console_tools.cpp`
- `../common/common_string_process.cpp`
- `txt_compare_main.cpp`
