# HDC Drawing

Draw mathematical graphics and cartoon characters using Windows HDC, with a drawing test harness.

The test harness references additional student demo functions that must be supplied or removed before linking.

## Build

Compile these source files together, with paths relative to this directory:

- `../common/cmd_console_tools.cpp`
- `../common/cmd_hdc_tools.cpp`
- `hdc_cartoon.cpp`
- `hdc_math.cpp`
- `test_draw_peppapig.cpp`
- `test_hdc.cpp`
