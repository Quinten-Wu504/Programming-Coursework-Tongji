# BMP Subtitles

Render text onto BMP images using command-line options, bitmap processing, and character glyph data.

Requires a BMP input image and the font data expected by the program.

## Build

Compile these source files together, with paths relative to this directory:

- `../common/class_aat.cpp`
- `../common/common_string_process.cpp`
- `bmp_subtitles.cpp`
- `bmp_subtitles_main.cpp`
