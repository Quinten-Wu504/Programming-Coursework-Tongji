# Tetris

Implement piece generation, rotation, movement, collision detection, line clearing, scoring, and levels in a console game.

## Build

Compile these source files together, with paths relative to this directory:

- `../common/cmd_console_tools.cpp`
- `../common/common_frame_construction.cpp`
- `../common/common_math_tools.cpp`
- `../common/common_star_print.cpp`
- `90-02-b1-console.cpp`
- `90-02-b1-main.cpp`
- `90-02-b1-tools.cpp`
