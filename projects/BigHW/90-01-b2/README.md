# PopStar

Generate a grid of stars, select connected groups to remove, update the board, and calculate scores using numeric and console-graphics views.

## Build

Compile these source files together, with paths relative to this directory:

- `../common/cmd_console_tools.cpp`
- `../common/common_frame_construction.cpp`
- `../common/common_star_print.cpp`
- `90-01-b2-base.cpp`
- `90-01-b2-console.cpp`
- `90-01-b2-main.cpp`
- `90-01-b2-tools.cpp`
